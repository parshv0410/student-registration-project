# Full Stack Student Registration System

A full stack web application built using Node.js, Express.js, MongoDB, and EJS.

## Features

- User Registration
- User Login
- Dashboard
- View All Users
- Edit User
- Delete User
- Logout System
- MongoDB Database Integration
- Responsive UI using Bootstrap

## Technologies Used

- HTML
- CSS
- Bootstrap
- JavaScript
- Node.js
- Express.js
- MongoDB
- EJS
- GitHub
- Render

## Installation

1. Clone the repository
git clone https://github.com/parshv0410/student-registration-project.git

2. Install dependencies
npm install

3. Start the server
node server.js

4. Open browser
http://localhost:3000

5. Live link
https://student-registration-project-8p09.onrender.com
